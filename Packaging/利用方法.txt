Local LLM

起動
スタートメニューの「Local LLM」から起動してください。
.NET、Rust、Python、Node.js を別途インストールする必要はありません。
Windows 11 x64 が必要です。推論サーバーの動作条件は各サーバーの説明を参照してください。
エディタとウェブ検索には Microsoft Edge / WebView2 が必要です。

モデルの指定
推論サーバーと GGUF モデルは同梱していません。別途用意し、初回は
サーバー設定の「実行ファイル」と「モデル」に絶対パスを指定してください。
既定の実行ファイルパスは runtime\native\local-rocm.exe です。

推論サーバー
画像や Claude / Codex の専用 API を使う場合は、対応するサーバーを用意してください。

保存データ
会話・設定は %LOCALAPPDATA%\LocalLlmGui に保存されます。
作業フォルダーの既定はドキュメントです。
モデルはインストール先の外で管理することを推奨します。
アンインストールは配布ファイルとショートカットを削除します。
会話・設定・後から追加したモデルなどのファイルは削除しません。
